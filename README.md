# Bases de Datos

Repositorio dedicado al desarrollo y aprendizaje de bases de datos.
Aqui ire subiendo las semanas conforme las vaya desarrollando.

---

## Semanas planificadas

| Semana | Tema | Estado |
|--------|------|--------|
| 1 | Analisis y planificacion de base de datos | Proximamente |
| 2 | Diseno y gestion de una base de datos local | Proximamente |
| 3 | Gestion de contenidos con MongoDB | Proximamente |

---

## Contenido por semana

### Semana 1 – Analisis y planificacion
- Identificacion de entidades y atributos
- Definicion de relaciones
- Boceto del modelo relacional

### Semana 2 – Diseno y gestion local
- Implementacion en base de datos relacional (SQLite / MySQL / PostgreSQL)
- Creacion de tablas, claves primarias y foraneas
- Operaciones CRUD basicas

### Semana 3 – Gestion de contenidos con MongoDB
- Modelado de datos no relacional
- Insercion y consulta de documentos
- Comparativa con SQL

---

## Tecnologias que usare

- SQL (para semana 1 y 2)
- MongoDB (para semana 3)
- Git y GitHub
